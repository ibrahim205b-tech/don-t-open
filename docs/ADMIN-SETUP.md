# إنشاء حساب المدير الأول واستعادة الوصول

لا يوجد أي حساب مدير أو كلمة مرور مكتوبة في الكود. نموذج التسجيل العام ينشئ حسابات «مستخدم» فقط، ولا يقبل حقل الدور.

## الإنشاء (مرة واحدة على الخادم)

```bash
ADMIN_NAME="إبراهيم علي الشويلي" ADMIN_PHONE=07XXXXXXXXX npm run admin:create
```

- كلمة المرور تُطلب مرتين بشكل مخفي (١٠ أحرف على الأقل، ولا تحتوي رقم الهاتف). لا تُطبع ولا تُسجَّل.
- في بيئة بلا طرفية تفاعلية (مثل بعض المنصات) مرّر `ADMIN_PASSWORD` لمرة واحدة ثم احذفه من متغيرات البيئة فوراً.
- إذا كان هناك مدير عام فعّال، لا يُنشأ حساب جديد (الأمر آمن للتكرار). لإضافة مدير عام ثانٍ عمداً: أضف `-- --add`.
- إذا كان الرقم مسجلاً كمستخدم، يُرقّى إلى مدير عام وتُعاد كلمة مروره وتُنهى جلساته.
- العملية تُسجَّل في سجل التدقيق (`bootstrap.super_admin`).

داخل Docker:

```bash
docker exec -it dalil env ADMIN_NAME="..." ADMIN_PHONE=07XXXXXXXXX node scripts/create-admin.ts
```

## على استضافة بلا طرفية (مثل Render)

اضبط `ADMIN_NAME` و`ADMIN_PHONE` و`ADMIN_PASSWORD` في متغيرات البيئة. عند الإقلاع، إذا لم يوجد مدير عام، يُنشأ الحساب ويُسجَّل في سجل التدقيق (`via: env`). بعد أول دخول احذف `ADMIN_PASSWORD` من الإعدادات. وجود المتغيرات لاحقاً لا ينشئ مديراً ثانياً ولا يغيّر كلمة المرور.

## بعد أول دخول

1. سجّل الدخول من `/login`.
2. إذا كان `ADMIN_REQUIRE_MFA=true` (الافتراضي في الإنتاج) سيُطلب تفعيل التحقق بخطوتين من `/account/security` قبل فتح `/admin`.
3. أنشئ حسابات المشرفين: يسجّل الشخص حساباً عادياً، ثم من «المستخدمون» يُمنح دور «مشرف» أو «مدير».

## تغيير البيانات

- كلمة المرور: «حسابي ← الإعدادات».
- الاسم ورقم الهاتف للمدير العام: عبر سكربت الخادم أو تحديث قاعدة البيانات مع نسخة احتياطية مسبقة.

## استعادة الوصول

إذا نُسيت كلمة المرور أو فُقد هاتف المصادقة (يتطلب الوصول إلى الخادم نفسه):

```bash
npm run admin:reset-password -- --phone 07XXXXXXXXX                 # كلمة مرور جديدة
npm run admin:reset-password -- --phone 07XXXXXXXXX --disable-mfa   # وإيقاف التحقق بخطوتين
```

تُنهى كل جلسات الحساب وتُسجَّل العملية. بعد الدخول فعّل التحقق بخطوتين مجدداً.

للمستخدمين العاديين: المدير يستطيع توليد كلمة مرور مؤقتة من «المستخدمون» بعد التحقق من هوية صاحب الحساب.
