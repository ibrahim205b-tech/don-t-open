# النسخ الاحتياطي والاستعادة

البيانات كلها في مكانين: ملف قاعدة البيانات (`DATABASE_PATH`) ومجلد الصور (`UPLOAD_DIR`).

## أخذ نسخة

```bash
npm run backup
```

- يستخدم واجهة النسخ الاحتياطي في SQLite (نسخة متسقة حتى والموقع يعمل).
- ينسخ الصور.
- يشغّل `integrity_check` على النسخة ويفشل إن لم تكن سليمة.
- يحتفظ بآخر ١٤ نسخة (`BACKUP_KEEP`).

جدولة يومية على الخادم (cron):

```cron
15 3 * * * cd /srv/dalil && /usr/bin/npm run backup >> /var/log/dalil-backup.log 2>&1
```

داخل Docker: `docker exec dalil node scripts/backup.ts` (النسخ تُحفظ في `/data/backups` على القرص الدائم).

**مهم:** انسخ مجلد النسخ إلى مكان خارج الخادم (تخزين سحابي أو جهاز آخر) أسبوعياً على الأقل، ويفضّل مشفراً. النسخ تحتوي أرقام هواتف المستخدمين.

## الاستعادة

1. أوقف الخادم.
2. احفظ الملفات الحالية جانباً (لا تحذفها).
3. انسخ `dalil.db` من النسخة إلى `DATABASE_PATH`، واحذف ملفات `-wal` و`-shm` القديمة بجانبها.
4. انسخ مجلد `uploads` إلى `UPLOAD_DIR`.
5. شغّل الخادم وتحقق من `/healthz` ومن صفحات عشوائية.

جرّب الاستعادة على جهاز آخر مرة كل شهر للتأكد من أن النسخ صالحة.
