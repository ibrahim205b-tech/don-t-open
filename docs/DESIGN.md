# قرارات التصميم

**الموضوع:** دليل حي لمنطقة المعامل في بغداد. مصدر الهوية البصرية هو لافتات المحلات العراقية المرسومة: خط كوفي عريض على لوح أخضر، وأصفر اللافتات والتكسي، وجدران بلون الجص.

| الرمز | القيمة | الاستخدام |
| --- | --- | --- |
| board | `#17594A` | الترويسة، الأزرار الأساسية، الأيقونات |
| sign | `#F2C230` | زر «أضف إعلانك» وخط الترويسة السفلي فقط |
| ink | `#1E2A2F` | النص والتذييل |
| ink-2 | `#4A585E` | النص الثانوي (تباين ٦٫٩:١) |
| plaster | `#EEF1EF` | خلفية الصفحة |
| surface | `#FFFFFF` | البطاقات والجداول |

- **الخطوط:** Noto Kufi Arabic للعناوين (روح اللافتة)، وIBM Plex Sans Arabic للنص. القاعدة ١٧px بسلم ١٫٢٥ لراحة كبار السن.
- **التخطيط:** البحث هو الواجهة الرئيسية. الإعلانات صفوف مدمجة بصورة مصغرة (أخف على الإنترنت الضعيف) بدل شبكة بطاقات متطابقة. المحاذاة لبداية السطر (اليمين).
- **الحركة:** ضغط الأزرار (scale ‎0.96 خلال ‎150ms)، فتح القوائم والنوافذ عند الطلب فقط، بلا حركات دخول عند التمرير، ومع احترام `prefers-reduced-motion`.
- **الوصول:** أهداف لمس ٤٤–٤٨px، رابط تخطي، تركيز ظاهر، ملخص أخطاء يأخذ التركيز، تسميات لكل حقل، `lang="ar" dir="rtl"`. Lighthouse: إمكانية الوصول ١٠٠.
- **الأداء:** صفحات من الخادم، ملف CSS واحد، JavaScript ٣ ك.ب اختياري، صور WebP مع `loading="lazy"`، ضغط Brotli/Gzip، وتخزين طويل للملفات ذات البصمة.
