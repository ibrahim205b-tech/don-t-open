# نتائج الاختبارات الأمنية والوظيفية

تاريخ آخر تشغيل: 2026-10-30، على Node 22.22 وChromium (Playwright 1.63). كل الاختبارات تعمل على نسخة محلية معزولة من التطبيق. لم يُختبر أي موقع أو خدمة خارجية.

## الملخص

| الفحص | الأمر | النتيجة |
| --- | --- | --- |
| فحص الأنواع | `npm run typecheck` | ناجح، بلا أخطاء |
| ESLint | `npm run lint` | ناجح، بلا أخطاء |
| اختبارات الوحدات والتكامل والأمن | `npm test` | ٣٨ من ٣٨ ناجحة |
| اختبارات المتصفح (Chromium حقيقي) | `npm run test:e2e` | ٣ من ٣ ناجحة، وبلا أي مخالفة لسياسة CSP |
| فحص التبعيات | `npm audit` | ٠ ثغرات معروفة |
| فحص الأسرار | الاختبار ١٥ في `tests/security.test.ts` | لا أسرار في الملفات المتتبعة أو الملفات العامة |
| Lighthouse (هاتف بشبكة بطيئة محاكاة) | الرئيسية، الوظائف، صفحة محل | الأداء ٩٥، الوصول ١٠٠، أفضل الممارسات ١٠٠، SEO ‏١٠٠؛ CLS ‏0، TBT ‏0–100ms، LCP ‏2.7s، الحجم ~٣٠٥ ك.ب |

## الاختبارات الوظيفية (tests/workflow.test.ts وtests/e2e)

الصفحات العامة كلها مع الحقوق ورقم الدعم؛ التسجيل والدخول والخروج؛ دورة المراجعة كاملة (إرسال → معلّق → موافقة → عام → تعديل → عودة للمراجعة)؛ الرفض بسبب إلزامي ومنع إعادة نشره؛ طلب التعديل وإعادة الإرسال؛ المسودات؛ الإخفاء والبلاغ والانتهاء والتجديد؛ ملكية الأنشطة والأصناف وحالة المحل وصلاحيات المالك؛ التقييمات (لا تقييم ذاتي، واحد لكل مستخدم، بعد المراجعة)؛ التوثيق اليدوي؛ طلبات المساعدة (الموافقة وإخفاء الرقم وإزالة الطلب)؛ البحث العربي والفلاتر؛ الحد اليومي ومنع التكرار. وفي المتصفح: التسجيل ثم نشر وظيفة بصورة عبر النموذج، وموافقة المدير، والظهور للعامة، والبلاغ، والقائمة على الهاتف، ورابط التخطي، وروابط الاتصال وواتساب، وعدم وجود تمرير أفقي على شاشة ٣٢٠px.

## ما لم يُنفّذ ويحتاج مراجعة

- **فحص ديناميكي آلي (DAST) مثل OWASP ZAP:** الأداة غير متوفرة في بيئة البناء. يُنصح بتشغيله على نسخة staging بعد النشر.
- **أداة فحص أسرار مخصصة (gitleaks/trufflehog):** غير متوفرة؛ استُخدم فحص بأنماط داخل الاختبارات. يُنصح بتفعيل GitHub Secret Scanning على المستودع.
- **اختبار على هاتف حقيقي:** القياسات بمحاكاة Lighthouse وشاشة Chromium بقياس الهاتف، لا على جهاز فعلي.
- **قارئ شاشة حقيقي** (TalkBack/VoiceOver): لم يُختبر يدوياً؛ الفحص الآلي للوصول نتيجته ١٠٠.
- **حمل عالٍ:** لم يُجرَ اختبار ضغط.
- **الاستضافة الحقيقية:** HSTS وTRUST_PROXY وحدود الوكيل العكسي تحتاج تحققاً بعد النشر.

نجاح هذه الاختبارات لا يعني أن المشروع خالٍ من الثغرات؛ يعني أن السيناريوهات المذكورة مغطاة ومُتحقق منها آلياً.
